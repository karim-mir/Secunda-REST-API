# Secunda REST API

RESTful API для работы со справочником организаций, зданий и видов деятельности. Приложение предоставляет функционал для поиска и фильтрации организаций по различным критериям.

## 🚀 Функциональность

### Организации
- **Получить информацию об организации** - GET `/organizations/{id}`
- **Поиск организаций по названию** - GET `/organizations/search?name=...`
- **Список организаций в здании** - GET `/buildings/{building_id}/organizations`
- **Список организаций по виду деятельности** - GET `/activities/{activity_id}/organizations`
- **Поиск по иерархии видов деятельности** - GET `/activities/search?name=...`
- **Поиск организаций в географической области** - POST `/organizations/nearby`

### Здания
- **Получить список всех зданий** - GET `/buildings`

### Виды деятельности
- **Иерархическая структура видов деятельности** (ограничение: 3 уровня вложенности)

## 🛠 Технологии

- **Python 3.11+**
- **FastAPI** - современный веб-фреймворк
- **Pydantic** - валидация данных и сериализация
- **Uvicorn** - ASGI-сервер для запуска приложения
- **SQLAlchemy** (опционально) - работа с базой данных
- **GeographicLib** (опционально) - расчеты расстояний

## 📦 Установка и запуск

### 1. Клонирование репозитория
```
git clone https://github.com/karim-mir/Secunda-REST-API.git
```
### 2. Создание виртуального окружения
```commandline
poetry init
```
### 3. Активация виртуального окружения
```commandline
poetry shell
```
### 4. Установить все зависимости из pyproject.toml
```commandline
poetry install
```
### 5. Запуск приложения
```commandline
python manage.py runserver
```
### 6. Заполнение тестовыми данными базу данных
```commandline
python manage.py seed_data
```
### 7. Создание суперпользователя(админа)
```commandline
python manage.py createsuperuser
```

## 🔍 Особенности реализации
- Иерархия видов деятельности ограничена 3 уровнями вложенности

- Географический поиск поддерживает поиск по радиусу и прямоугольной области

- Рекурсивный поиск по дереву видов деятельности

- Единый формат ответов - все ответы в формате JSON
